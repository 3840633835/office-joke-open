One line of office comedy for make.fun's "Make the AI Judge Laugh: the Office Joke Open" ($2, winner-takes-all). A judge model reads the jokes two at a time and keeps the funnier one on every pass, so the entry is a single joke built to survive head-to-head comparisons: a specific office detail, a turn that pays off in the last few words, and nothing extra.

The entry (69 characters, within the 200-character cap):

> The fire drill is the only project this office ever delivers on time.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (exactly 69 bytes, no trailing newline). See [METHODOLOGY.md](METHODOLOGY.md) for how the line was chosen: 35 fresh candidates scored against the judge's brief, a study of 1,200 competitor titles, and the head-to-head that picked the winner.
